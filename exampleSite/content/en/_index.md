This page is the documentation index. The demo site turns on
`params.landing`, so its home page is the hero instead - set it to `false`
and this is what the home page shows: an ordinary page with the sidebar and
the table of contents.

## Sections

- [Getting started](/getting-started) - install the theme and write a first page.
- [Writing](/writing) - markdown, code blocks and shortcodes.
- [Customization](/customization) - colours, logo, landing page, languages.
- [Reference](/reference) - front matter, configuration, icons, an API page.
- [Changelog](/changelog) - the changelog layout.

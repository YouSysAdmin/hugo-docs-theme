The theme as a package of its own, with a demo site.

## Added

- Root-relative links and links to content files resolve against `baseURL`.
- `assets/css/custom.css` is picked up without configuration.
- `hooks/head-end.html` and `hooks/body-end.html` partials.
- `logo`, `favicon`, `themeColor`, `copyright`, `externalLinksNewTab` and
  `get_started_url` parameters.
- The OpenAPI reference layout takes a page resource, a path or a URL.

## Changed

- Code is set in JetBrains Mono. Space Mono stays for labels.

- Scalar is published only by a site with a reference page.
